Where these numbers come from
  • Logistic Regression (composite target, Phase 5a–6) scores each candidate as intercept + Σ coefficient × feature value, shown as the compatibility index (0 = decision boundary). Bars: coefficient × (value − training mean), the closed-form SHAP value for a linear model. It's shown as an index, not a probability, because this model separates the data almost perfectly (held-out ROC-AUC ≈ 0.9995), so its probabilities saturate near 100% and hide real differences between candidates. That's expected: the composite target was itself built from earlier-stage models on very similar features.
  • Decision Tree and Random Forest (same target and features) give the probability of a high-quality match. Bars are exact TreeSHAP values in percentage points, computed in your browser with the same algorithm as shap.TreeExplainer (checked against it to within 10−6). The Decision Tree is shallow (depth 5), so you can also read the exact rule path it followed. Because it has few leaves, many Mates tie; ties are broken by Mate ID.
  • SVM (RBF kernel, standardised features, same target) ranks by its margin: the signed distance from the decision boundary (0 = boundary, positive = high-quality side). Like Logistic Regression it separates the data almost perfectly (held-out ROC-AUC ≈ 0.9996), so the margin is shown rather than a saturated probability. Bars are exact Shapley values of the margin against an average training pair (all 210 feature combinations evaluated in your browser; checked against shap.KernelExplainer). Age gap and age score always move together in real data, so their two bars are best read as one.
  • k-Nearest Neighbours looks up the k past pairings (training data) most similar to this one and reports the share that were high-quality. k was picked by cross-validation on training users only. The explanation is the neighbours themselves: open "Closest past pairings" on a card.
  • k-means is unsupervised: it grouped the training pairings into k clusters by their 10 features alone, without seeing outcomes (number of clusters picked by silhouette score). Each cluster's score is the share of its training pairings that turned out high-quality, so every Mate in the same cluster gets the same score and ties are common (broken by Mate ID). Bars show what makes the cluster different from an average pairing, in standard deviations.
  • Age only is the Phase 4 age-based baseline: smallest age gap first, nothing else considered.
  • Current rule stands in for NoCatch's existing rule-based score (existing_rule_score). Its exact formula isn't available, so this demo uses a linear reconstruction fitted to it from the same 10 features (held-out R² —). The ranking numbers below are for the original rule score.
